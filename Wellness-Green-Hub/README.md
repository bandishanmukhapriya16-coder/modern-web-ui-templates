# 🌿 Wellness Green Hub

A collection of four modern, responsive web applications designed around wellness, smart living, gardening, career development, and personal routine management.

## 📌 Applications

Combines gardening information with a clean dashboard-style experience suitable for modern lifestyle applications.

**Implementation Highlights:**

* Responsive garden dashboard

* Favorites interaction

# 🔎 Research and Observations

While designing these applications, common patterns from modern consumer and productivity interfaces were considered.

### Observed Patterns

1. **Dashboard-first layouts**
   Important information is presented through cards and visual summaries.

2. **Clear visual hierarchy**
   Large headings, supporting descriptions, and primary actions guide users through each interface.

3. **Card-based information**
   Cards make complex information easier to scan and organize.

4. **Progress visualization**
   Health scores, progress bars, and status indicators make information easier to understand.

5. **Responsive design**
   Layouts adapt to desktop, tablet, and mobile screen sizes.

6. **Dark mode**
   Dark mode provides an alternative visual experience and demonstrates modern UI expectations.

7. **Interactive feedback**
   Toast messages and state changes provide immediate feedback when users interact with controls.

# ▶️ How to Run

Each application is a standalone HTML/CSS/JavaScript project.

### Method 1 — VS Code

1. Open the `Wellness-Green-Hub` folder in VS Code.
2. Open any application folder.
3. Open `index.html`.
4. Right-click the file.
5. Select **Open with Live Server**.

### Method 2 — Browser

Open the application's `index.html` file directly in a modern web browser.

Recommended browsers:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
